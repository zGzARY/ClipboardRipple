# ClipDock

ClipDock is a local-only clipboard history app for macOS. It is an independent implementation built with SwiftUI, AppKit, SwiftData, and native system frameworks.

The repository root is the canonical source workspace.

## Privacy defaults

- Clipboard content stays on this Mac.
- There is no network entitlement, analytics SDK, or cloud sync.
- Confidential, transient, and autogenerated pasteboard types are ignored.
- Unpinned history is retained for 1 day by default and can be configured from 1 to 30 days.
- Browsing history, Pinboards, search, and restoring an item to the clipboard require no Accessibility permission.
- The default action copies the selected item back to the clipboard; press `⌘V` in the target app.
- Automatic insertion into another app is optional and requires macOS Accessibility permission because it sends a synthetic `⌘V` event.

## Interface and shortcuts

- Clipboard cards use a sticky-note layout with a color-coded type header.
- Clipboard images support PNG, TIFF, JPEG, HEIC, GIF, and WebP representations.
- The source application's real icon appears in the card header, with its name in the footer.
- ClipDock presents the panel from the bottom edge and dismisses it downward on Escape or loss of focus.
- A single pointer position drives a Dock-like cosine magnification curve across the hovered note and its neighbors; it adds no timer or per-card event monitor.
- A single click selects immediately; a double-click attempts to insert the note at the original app's cursor without delaying the first click.
- Reduce Motion disables ClipDock movement, and Reduce Transparency replaces the glass shelf with a solid system background.
- The display shortcut defaults to `⇧⌘V`; `⌃V`, `⌥⌘V`, and `⌃⌥V` are available in Settings.

## Build

```sh
xcodebuild -project ClipDock.xcodeproj -scheme ClipDock -configuration Debug build
xcodebuild -project ClipDock.xcodeproj -scheme ClipDock -configuration Debug test
```

Development builds use Xcode's local ad-hoc signature. For a stable local installation and persistent Accessibility identity, select a Personal Team in the target's Signing & Capabilities settings before producing the Release build.

See [SIGNING.md](SIGNING.md) for the exact Personal Team handoff and verification gates.

The installed app belongs at `/Applications/ClipDock.app`. Xcode places local build products in the selected Derived Data directory.

## Local ZIP distribution

An ad-hoc-signed `ClipDock.app` can be transferred directly in a ZIP archive without a DMG. After extracting it, drag the app to `/Applications` and use Finder's **Open** command from the context menu on first launch. If macOS still reports that it cannot verify the developer, remove quarantine only from this app and open it again:

```sh
xattr -dr com.apple.quarantine /Applications/ClipDock.app
open /Applications/ClipDock.app
```

This local distribution is not Developer ID signed or notarized. Do not disable Gatekeeper globally for a single application. Automatic insertion requires the receiving user to grant Accessibility permission; clipboard history, selection, and restoring content to the clipboard do not.

## Acceptance gates

- Keep the app free of third-party packages, analytics, cloud sync, and network code.
- Remove declarations and persisted fields that do not support a confirmed feature.
- Run the unit suite twice consecutively, then perform a clean Release build.
- Verify permission-free clipboard restoration and optional Accessibility-gated automatic paste separately.
- Verify the installed signature, empty entitlement set, launch behavior, source icons, and all four display shortcuts.
- Keep the installed Release app below 10 MB unless a confirmed feature justifies the increase.
